01

Amadeus

A local AI companion that runs on a normal gaming PC

A fan project I built to see if a full companion AI could run on consumer hardware. It can if you pick your tradeoffs well.

Voice
Browser audio goes through voice detection, speech to text, a local model and text to speech. You can interrupt it mid sentence and every stage stops.
Memory
After each session it merges duplicates and catches contradictions. Mood changes are capped so one bad chat can't wreck it.
Avatar
A Live2D hook drives expressions from tags in the reply. The tags get stripped before it speaks.
Reliability
Startup recovery, job limits and a GPU fallback.

Python · FastAPI · WebSockets · SQLite · Ollama · faster-whisper
